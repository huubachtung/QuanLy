# Project Description

Company name: Juss_TV
`app` is a Flutter-based mobile application designed for internal use by the company's employees. It functions as a comprehensive management portal for various business processes, replacing traditional Excel and Google Sheets workflows. The application streamlines operations by providing real-time data access, automated notifications, and intuitive user interfaces for key business functions.
